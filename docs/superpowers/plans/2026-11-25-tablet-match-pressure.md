# 태블릿 색 해금과 실패 증원 계획

> Unity 2022.3.8f1에서 재현과 회귀를 완료했습니다.

목표는 클릭이 사용한 색 순환 범위와 실제 보충을 일치시키고, 새 수리·방어막 색을 예고한 뒤 보여주며, 유효한 실패 탭 세 번에 소형 증원 한 묶음을 늘리는 것입니다.

- [x] `TabletSceneTests.cs`에서 해금 경계를 넘기는 진행 중인 매치, 수리칸의 예고 없는 변경, 실패 세 번 뒤 다음 편대의 실제 기체 수를 재현합니다.
- [x] `Game.cs`, `TabletBoardPalette.cs`에서 태블릿 매치 시작의 팔레트를 보충 완료까지 유지합니다. 안정화 이후 해금을 반영합니다. 수리 4초와 방어막 30초에는 0.5초 동안 입력을 허용한 채 칸 표시를 한 뒤 최초 그룹을 제공하고, 사용자가 그사이 성공하면 보드가 다시 안정된 후 예고를 재개합니다. 유도 18초와 폭발 42초는 일반 보충으로 등장합니다.
- [x] `MatchFeedbackPanel.cs`에서 색 순서·순환, 실제 탭과 이웃의 전후, 다음 잠금 색, 첫 지원 그룹, 실패 1/3·2/3과 증원 상태를 짧게 표시합니다. 계산 가능한 유효 매치가 없으면 보충하고 실패로 집계하지 않습니다.
- [x] `TabletReinforcements.cs`에서 대기 1묶음, 일반 스폰 묶음마다 최대 한 번, 정규 증원 후 소형 지원기 3기 한 번으로 제한합니다. 여분 적은 별도 재화를 지급하지 않고 보스를 복제하지 않습니다. 충돌·적탄·격파에 실제 기체로 포함하고 시간 종료와 Retry에서 대기를 비웁니다. `TabletCombat.cs`의 적 계획과 적중 비트마스크 크기, `TabletView.cs`의 재사용 슬롯과 정산 총수를 맞춥니다.
- [x] Unity 2022.3.8f1에서 Red→Green, 전체 PlayMode, 4:3와 mini 정상 속도 플레이 및 원래 02.Game 재검증을 수집합니다. PR #13 위에 별도 변경으로 올립니다.
