# 태블릿 퍼즐 효과 아이콘 계획

> 기존 전담 Orca 워커가 03.TabletPuzzleShooter 범위에서 구현하고 실제 Unity 화면으로 확인합니다.

- [x] 플레이 모드 회귀에서 타일과 하단 팔레트가 같은 효과 스프라이트를 사용하고, 02.Game 타일은 원래 얼굴 스프라이트를 사용한다는 계약을 추가합니다.
- [x] 내장 ImageGen으로 생성한 투명 원본에서 일곱 아이콘을 셀 단위로 자릅니다. 빨강 직선, 주황 관통, 노랑 확산, 초록 수리, 하늘 유도, 파랑 방어막, 보라 폭발의 기존 색 ID와 대응시킵니다.
- [x] 03 모드에서만 Block, 팔레트와 발사·수리·방어막 표시가 같은 아이콘으로 그려지게 주입합니다. 타일의 배경색과 이웃 색 전환 규칙은 그대로 읽히게 합니다. 물리 투사체와 세로 퍼즐의 얼굴 및 진입 경로는 각자의 기존 리소스를 사용합니다.
- [x] 4:3과 mini의 실제 Game View에서 보드와 피드백을 검증합니다. 02.Game의 매칭·점수·보충·종료·Retry를 직접 다시 확인합니다.
