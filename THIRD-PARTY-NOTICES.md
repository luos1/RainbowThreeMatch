# Third-party audio notices

## Interface Sounds 1.0 by Kenney

The game uses five original Ogg Vorbis files from Kenney's Interface Sounds 1.0 pack. Kenney released the pack under the **CC0 1.0 Universal** public domain dedication. The pack specifically allows commercial use and makes credit optional. CC0 allows copying, modifying and distributing the assets as part of the game. [Kenney asset page](https://kenney.nl/assets/interface-sounds) · [Kenney's OpenGameArt submission](https://opengameart.org/content/interface-sounds) · [CC0 1.0 legal code](https://creativecommons.org/publicdomain/zero/1.0/legalcode)
